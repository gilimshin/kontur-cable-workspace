Контур: автоматический локальный запуск

После установки сайта запускается автоматически при входе пользователя в Windows.
Сервер работает в фоне, затем открывается http://127.0.0.1:8765/.

На каждом компьютере выполните один раз:
1. Скопируйте start_kontur.ps1, install_autostart.ps1, remove_autostart.ps1,
   install_autostart.bat и обновлённый start_kl.bat в папку cable-workspace,
   рядом с server.py.
2. Дважды щёлкните install_autostart.bat.
3. Выйдите из Windows и войдите снова либо запустите start_kl.bat для немедленного запуска.

Для отключения автозапуска запустите remove_autostart.ps1 в PowerShell.
Локальный сайт доступен только на том компьютере, где запущен сервер.
Для общего доступа дома и на работе используйте облачную ссылку Vercel.
